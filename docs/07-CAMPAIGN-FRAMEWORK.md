# Berry Voice — Launch Campaign Framework
Owner: TES — Task Expert Systems.

Prospecting and product/customer telemetry are separate data domains.

## Wave 1
FMCG—order capture; Logistics—tracking/delivery exceptions; Automotive—bookings; Healthcare—appointments; BPO—deployable AI-agent platform.

## Pipeline
RESEARCHED → PERMISSION_REQUEST_READY → PERMISSION_REQUEST_SENT → CONSENTED/DECLINED → PERSONALISED_DEMO_INVITE → DEMO_BOOKED → PILOT_DISCUSSION → PROPOSAL → WON/LOST/HOLD/SUPPRESSED.

Store company, contact, role, public source, contact source, segment/use case, consent status, contact dates, message version, response, next action and suppression.

Do not guess personal email formats. Enforce direct-marketing compliance/suppression before send.

## Mail operating model
Research one prospect; draft permission-oriented message; human reviews; send from authorised TES/user mailbox; record outcome; after positive response send personalised demo invite; durable suppression on decline. Start one-at-a-time and version message variants.
